# F13 — Productive Acceptance Blockers

F13 is a separate **acceptance gate**, not an automatic extension of simulated engineering success.

| Gate | Current status | Closure requirement |
|---|---|---|
| External adapter authorization | BLOCKED | Explicitly authorized integration and scopes, including provider terms |
| F08 promotion | BLOCKED | Real benchmark and qualification evidence; Production state only through authorized promotion |
| Paid mission | NOT PROVEN | A real eligible task must execute end-to-end with independent external completion evidence |
| Actual revenue | NOT PROVEN | Separate externally reconcilable receipt/settlement; no fabricated F10 earning or cash |
| Recovery under productive constraints | NOT PROVEN | Safe replay/fencing evidence on the authorized platform |
| End-to-end one-command acceptance | PENDING | Full production gate, not just local rehearsal |
| GNATprove SPARK proof | TOOLCHAIN UNAVAILABLE | Optional formal claim requires actual GNATprove output |

F13 engineering tests use only local deterministic input and synthetic accounting and are eligible for candidate tagging, **not `MISSION_PROVEN`**.
